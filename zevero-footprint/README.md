# Zevero Footprint Calculator

This is a minimal Next.js + Tailwind app containing the Zevero Footprint Calculator.

## Local dev

```bash
npm install
npm run dev
# open http://localhost:3000
```

## Deploy to Vercel

1. Create a new repo and push:
   ```bash
   git init
   git add -A
   git commit -m "initial"
   git branch -M main
   git remote add origin <your-repo-url>
   git push -u origin main
   ```
2. Go to https://vercel.com → **New Project** → **Import** your repo → **Deploy**.
3. Vercel auto-detects Next.js. No extra settings needed.
